# 🎨 Color Tap

A simple, fun game for young children (ages 3-7) to learn colors.
The game shows a color name, and the child taps the matching colored button.

## How to Play
1. Read the color word shown on the screen (for example, "RED").
2. Tap the button with the matching color.
3. A right answer gives +1 point and a happy message.
4. A wrong answer shows "Try again!"
5. Press "Start over" to reset the score.

## Features
- 4 colors: red, blue, green, yellow
- Score counter
- Random color words
- Big, easy-to-tap buttons for small hands
- Works on phones, tablets, and computers
- Light and dark mode support

## Built With
- HTML
- CSS
- JavaScript (no libraries needed)

## How to Run
1. Download or clone this repository.
2. Open `color-tap.html` in any web browser.

That's it. No installation needed.
